\# AI Patient Case Taking System



An AI-assisted patient case-taking system developed as a team project for Medikiosk.



\## Project Overview



The system is designed to collect patient information and clinical history through a structured interface and process the information using backend and AI-related components.



\## Project Modules



\### Frontend

Provides the user interface for entering patient information and clinical details.



\### Backend

Handles the Flask application, routes, form submission, and server-side processing.



\### AYUSH Module

Handles AYUSH-related clinical history information.



\### AI Model

Contains components intended for AI-based analysis of patient case information.



\### ABDM Integration

Provides the structure for integration with the Ayushman Bharat Digital Mission (ABDM) ecosystem.



\### Database

Contains components related to storing and managing patient case information.



\### Documentation

Contains project documentation and information about the system.
