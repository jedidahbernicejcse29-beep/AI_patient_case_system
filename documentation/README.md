\# Documentation



This folder contains documentation for the AI Patient Case Taking System.



\## Purpose



The documentation helps the development team understand the project structure, modules, features, and usage.



\## Project Modules



\- `backend` – Handles server-side logic and API functionality

\- `frontend` – Provides the user interface

\- `ai\_model` – Contains AI-related components

\- `ayush\_module` – Handles AYUSH clinical history

\- `abdm\_integration` – Handles ABDM-related integration

\- `database` – Contains database-related components



\## Team Development



Each team member can work on a separate branch and submit changes through a Pull Request.



\## Version Control



The project uses Git and GitHub for version control and team collaboration.
