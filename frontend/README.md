\# Frontend Module



This module contains the user interface for the AI Patient Case Taking System.



\## Files



\- `index.html` – Main landing page

\- `patient\_form.html` – Patient information and case-taking form

\- `README.md` – Frontend documentation



\## Purpose



The frontend provides a simple interface for users to enter and view patient case information.



\## Integration



The frontend is designed to communicate with the backend of the AI Patient Case Taking System.



\## Technologies



\- HTML

\- CSS

\- JavaScript
