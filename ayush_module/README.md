

\# AYUSH Clinical History Module



This module is part of the AI Patient Case Taking System for Medikiosk.



\## Purpose



The AYUSH module collects clinical history information related to AYUSH healthcare systems and helps organize patient information for further processing.



\## Features



\- Collects patient clinical history

\- Supports AYUSH-related case information

\- Provides a structured history form

\- Integrates with the main patient case-taking system



\## Files



\- `ayush\_history.html` – Clinical history form

\- `models.py` – Data models

\- `routes.py` – Routes for the AYUSH module

\- `README.md` – Module documentation



\## Integration



The AYUSH module is designed to work with the backend and other modules of the Medikiosk AI Patient Case Taking System.
